# MeshWeaver Setup Guide



## Prerequisites

- Python 3.10 or a compatible version supported by the project

- Git

- Visual Studio Code or another code editor



## Create a Virtual Environment

```powershell

python -m venv .venv

.\.venv\Scripts\Activate.ps1

```



## Install Dependencies

```powershell

python -m pip install -r requirements.txt

```



## Run Tests

```powershell

python -m pytest

```



## Troubleshooting

- If Python is not recognized, check that Python is installed and added to PATH.

- If activation is blocked, follow your organization's security policy.

- If dependency installation fails, check the error message.
