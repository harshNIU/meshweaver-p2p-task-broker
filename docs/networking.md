
# MeshWeaver Networking Module

## Purpose

The networking module enables communication between
MeshWeaver peer nodes using asynchronous networking.

## Responsibilities

- UDP communication for control messages.
- Sending and receiving messages between peers.
- PING and PONG communication.
- Peer timeouts and retries.
- TCP streams for task payloads and results.
- Secure communication in later development stages.

## Technologies

- Python
- asyncio
- UDP sockets
- TCP streams
